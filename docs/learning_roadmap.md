### 📌 阶段一：机器人学理论基石与仿真环境构建（第 1 个月）[仿真篇]
- **核心目标**：掌握空间姿态描述（四元数、旋转矩阵），在纯仿真中拉起 SO-100M 模型。
- **理论学习**：
  - 《机器人学导论》(Craig) 第 1~4 章：刚体变换、DH 参数法、正逆运动学推导。
  - 空间齐次变换矩阵 $T \in SE(3)$、四元数与 Euler 角转换。
- **工程实践**：
  - 搭建 Ubuntu 22.04 + ROS 2 Humble 开发环境，掌握 `colcon build` 与 Git 工作流。
  - 深入掌握 ROS 2 节点 (Node)、话题 (Topic)、服务 (Service) 与 TF2 坐标树系统。
  - 接入 MuJoCo / Gazebo 物理仿真环境，加载 SO-100M 仿真机械臂。
- **项目落地**：
  - 完成 `so_arm101_description` URDF/XACRO 编写，使用 `robot_state_publisher` 和 RViz 2 / MuJoCo 发布与可视化仿真机械臂姿态。

### 📌 阶段二：仿真中的运动学算法、MoveIt 2 与轨迹规划（第 2 个月）[仿真篇]
- **核心目标**：在安全无损的仿真环境中调试 Pinocchio DLS IK 求解器与 MoveIt 2 避障。
- **理论学习**：
  - 雅可比矩阵 $J(q)$、微分运动学与奇异点概念。
  - 阻尼最小二乘法 (DLS) 逆运动学求解方程：$\Delta q = J^T (J J^T + \lambda^2 I)^{-1} e$。
  - 五次多项式插值与 3D 双扭线 (Bernoulli Lemniscate) 轨迹生成方程。
- **工程实践**：
  - 学习 Pinocchio C++/Python 动力学与运动学计算库。
  - 使用 MoveIt Setup Assistant 配置 `so_arm101_moveit_config`，在 RViz 2 中验证 OMPL 规划算法与碰撞检测。
- **项目落地**：
  - 在 `so_arm101_model_based` 中实现自定义数值 IK 解算器，在 RViz 2 / MuJoCo 仿真中平滑绘制 3D 8字形运动迹线与圆弧轨迹。

### 📌 阶段三：仿真中主从遥操作、虚拟双摄与仿真数据集采集（第 3 个月）[仿真篇]
- **核心目标**：在接触实物硬件前，先在仿真中调通整个 LeRobot 数据流与虚拟抓取流程。
- **理论学习**：
  - 虚拟手柄/键盘姿态映射逻辑。
  - 虚拟相机内参及 Pinhole 相机模型。
  - HuggingFace LeRobot 框架设计理念与 HDF5 / Zarr 格式特征组织。
- **工程实践**：
  - 在 MuJoCo 仿真中搭建虚拟抓取场景（桌子、积木块、虚拟双摄像头 Eye-in-Hand + Eye-to-Hand）。
  - 使用键盘/摇手柄在仿真中遥控机械臂完成虚拟抓取，录制 LeRobot 格式仿真数据集。
- **项目落地**：
  - 完全在仿真中跑通数据录制 ➔ 训练代码 ➔ 仿真策略闭环评估，确保算法架构无死角。

---

### 📌 阶段四：实物机械臂驱动、串口通信与手眼标定（第 4 个月）[实物篇]
- **核心目标**：算法在仿真中全部调通后，正式进军真实物理 SO-100M 机械臂与真实相机！
- **理论学习**：
  - 串口通信协议 (Baud rate 1M, STS3215 寄存器读写)。
  - 手眼标定数学原理：$AX = XB$ 求解 (Tsai-Lenz 算法)。
  - ArUco / AprilTag 码位姿估计与真实相机内参标定。
- **工程实践**：
  - 编写 Python/C++ 串口驱动程序，按 50Hz 频率收发真实角度数据与控制指令。
  - 配置真实双摄像头（主视角 Eye-to-Hand + 臂端 Eye-in-Hand），使用 OpenCV 进行相机标定与外参计算。
- **项目落地**：
  - 开发 `so_arm101_hardware`，实现上位机控制真实 SO-100M 机械臂复现阶段二的 8字形运动轨迹。
  - 实现真实环境中基于视觉 Tag 识别的目标定点 Pick & Place 闭环展示。

### 📌 阶段五：真实主从双臂遥操作采集、ACT 训练与 Sim2Real 实物 Demo（第 5-6 个月）[实物与 Sim2Real 进阶篇]
- **核心目标**：利用真实主从双臂采集高质数据集，在本地 RTX 4060 GPU 上训练 ACT / Diffusion Policy 策略模型，完成实物端到端自主抓取 Demo 展示。
- **理论学习**：
  - ACT (Action Chunking with Transformers) 算法机制：CVAE 变分自编码器 + Transformer 结合。
  - 显存与算力优化：FP16 混合精度训练、Batch Size 8~16 优化策略。
  - Sim2Real 域随机化 (Domain Randomization) 理念。
- **工程实践**：
  - 利用真实主从双臂 (Leader-Follower) 高效拖拽遥操作，录制 50~100 组真实物体抓取数据集。
  - 在本地 RTX 4060 (8GB VRAM) 上训练 ACT 策略模型。
  - 编写 ROS 2 推理节点 `so_arm101_learning_based`，将网络输出的 Action Chunk 实时转译为关节控制角。
- **项目落地**：
  - 部署自主抓取闭环策略，实现 SO-100M 实物在未见过位置下的物体识别与稳定抓取。
  - 录制流畅的视频 Demo，撰写系统性技术总结文档，作为求职核心 Portfolio。

## 三、 本地算力与硬件资源优化（RTX 4060 + SO-100M 双臂）

针对您现有的硬件配置，我们规划了如下高效研发策略：

1. **RTX 4060 (8GB VRAM) 训练优化**：
   - **模型选择**：优先采用 **ACT (Action Chunking with Transformers)**，其轻量级结构仅需约 3~5 GB 显卡内存，在 4060 上 2~3 小时内即可收敛。
   - **训练加速**：启用 `torch.cuda.amp` 混合精度与 PyTorch 2.0 `torch.compile`，优化数据加载 DataLoader CPU 线程数。
2. **先仿真后实物数据流贯通**：
   - 阶段 3 在 MuJoCo 仿真中打通 LeRobot 格式 ➔ 阶段 5 零痛点迁移到真实主从双臂数据采集。
